# VPS Computer — Diploma Course Experience

A cinematic, interactive course showcase for **VPS Computer**, located in **Kalyan Kendra Township, Begusarai**.

This repository presents a polished, browser-based learning portal that introduces visitors to three computer education pathways: **DCA**, **DFA**, and **ADCA**. Rather than behaving like a traditional academic website, it uses a visual, immersive presentation to make each curriculum feel like an experience.

## What the site contains

### Home experience

The landing page introduces VPS Computer and invites visitors to explore the available diploma programmes. It features:

- A dark, cinematic visual identity
- Animated particle and constellation effects
- Glass-style interface panels
- Responsive layouts for desktop and mobile screens
- Direct navigation to each course experience

### DCA — Diploma in Computer Applications

The DCA page presents a practical foundation in everyday computer applications. Its syllabus covers:

- Computer fundamentals, hardware, software, memory, and devices
- Windows operating system basics and file management
- Microsoft Word and professional document creation
- Microsoft Excel, formulas, charts, and data analysis
- Microsoft PowerPoint and presentation design

The course content is displayed as an interactive module grid with animated cards and a focused, distraction-free visual style.

### DFA — Diploma in Financial Accounting

The DFA page presents its curriculum through a rotating 3D carousel. It introduces learners to:

- Computer fundamentals
- Windows basics
- Microsoft Word
- Microsoft Excel
- Microsoft PowerPoint
- HTML fundamentals
- Internet and email basics
- Tally Prime, accounting, ledgers, inventory, and GST

The page uses a deep-space-inspired interface with cinematic transitions, hover interactions, particle effects, and responsive mobile presentation.

### ADCA — Advanced Diploma in Computer Applications

The ADCA page expands the learning journey into a broader advanced-computer curriculum. It includes:

- Computer fundamentals and Windows basics
- Microsoft Word, Excel, and PowerPoint
- HTML and internet fundamentals
- Tally Prime and accounting concepts
- Video and audio editing fundamentals
- Photoshop basics, layers, masks, and graphic design

Its content is presented as an animated 3D learning carousel with a distinctive crimson and orange visual theme.

## Visual direction

The site is designed around a premium, cinematic aesthetic:

- Dark backgrounds with neon cyan, violet, crimson, and orange accents
- Typography combining **Cinzel** and **Montserrat**
- Glassmorphism panels and soft lighting effects
- Particle backgrounds inspired by stars and constellations
- Hover states, parallax movement, 3D rotation, and animated introductions
- Responsive behaviour that changes complex desktop scenes into readable mobile layouts

## How to view the site

Open `index.html` in a modern web browser, then choose a course from the landing page. The pages are static HTML experiences and are intended to be explored directly in the browser.

Some visual elements use externally hosted resources, including Google Fonts and the Particles.js library, so an internet connection may be needed for the complete visual presentation.

## Project purpose

VPS Computer is presented here as more than a list of courses: it is a digital introduction to practical computer education. The experience combines clear curriculum information with a memorable visual language to help prospective learners discover the programme that fits their goals.
